## ✨ Primeros Pasos

### Explorar el Sistema
```
1. Abre el archivo
2. Verás 6 pestañas arriba:
   - 📍 Departamentos
   - ✅ Tareas
   - 📅 Reuniones
   - 📌 Mural
   - 📊 Asistencia
   - 📢 Comunicados
```

### Agregar Tu Primer Miembro
```
1. Ve a DEPARTAMENTOS
2. Haz clic en una tarjeta (ej: "EQUIPO TÉCNICO")
3. Presiona "+ Agregar"
4. Rellena:
   - Nombre: "Tu Nombre"
   - Rol: "Tu Posición"
5. Presiona "Guardar"
```

### Crear Tu Primera Tarea
```
1. Ve a TAREAS
2. Presiona "+ Nueva Tarea General (Para Todos)"
3. Rellena:
   - Título: "Mi tarea"
   - Tu Nombre: "Tu Nombre"
4. Presiona "Crear Tarea"
```

### Agregar Nota al Mural
```
1. Ve a MURAL
2. Presiona "+ Nueva Nota"
3. Rellena:
   - Asunto: "Mi nota"
   - Contenido: "Lo que quiero compartir"
   - Tu Nombre: "Tu Nombre"
4. Presiona "Crear Nota"
```

## ❓ Preguntas Frecuentes

**P: ¿Necesito internet?**
R: No, funciona 100% offline. Los datos se guardan en tu navegador.

**P: ¿Dónde se guardan los datos?**
R: En tu navegador (localStorage). Solo accesible desde este navegador.

**P: ¿Puedo usar en móvil?**
R: Sí, es responsive. Abre el archivo en navegador del móvil.

**P: ¿Se pierden los datos?**
R: Solo si limpias el caché. Por eso: exporta regularmente a CSV.

**P: ¿Puedo compartir datos con otros?**
R: Sí, exporta a CSV. Otros pueden verlo en Excel o reimportar.

**P: ¿Es gratis?**
R: Completamente gratis. Uso interno CESI.

**P: ¿Puedo modificar el código?**
R: Sí, está hecho para extender. Modifica según necesites.

## 🛠️ Si Algo No Funciona

### El archivo no abre
```
✓ Verifica que los 3 archivos estén juntos
✓ Intenta con otro navegador (Chrome, Firefox)
✓ Abre desde una carpeta, no desde Descargas
```

### Se ve en blanco
```
✓ Presiona F5 (recargar)
✓ Presiona Ctrl+Shift+R (caché completa)
✓ Abre consola: F12 → Console → Busca errores rojos
```

### Los datos no se guardan
```
✓ Abre F12 → Console
✓ Busca errores (rojo)
✓ Copia el error y busca solución
```

### CSS no se aplica
```
✓ Verifica que styles.css esté EN LA MISMA CARPETA
✓ Verifica que el nombre sea exactamente "styles.css"
✓ Recarga página (Ctrl+Shift+R)
```
